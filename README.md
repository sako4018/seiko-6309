# Seiko 6309-8060 — The Watchmaker's Lab

Интерактивен 3D дигитален двойник на моя винтидж **Seiko 5 Automatic 6309-8060** с автоматичния механизъм **калибър 6309** вътре. Работи директно в браузъра (Three.js + WebGL).

**Живо демо:** https://sako4018.github.io/seiko-6309/

## Какво може

| Режим | Какво показва |
| --- | --- |
| **Watch** | Целият часовник: въртене на 360°, zoom, въртяща се платформа |
| **Case** | Корпус, стъкло, циферблат, стрелки, коронка, гривна; заден капак, който се отваря |
| **Movement** | Механизмът откъм капака: мостовете и роторът могат да се скриват, роторът се върти с мишката |
| **Exploded** | Частите, разделени по слоеве, с плъзгач 0–100 % |
| **Assembly** | Сглобяване стъпка по стъпка (21 стъпки) с обяснение за всяка част |
| **Simulation** | Енергийният път в движение, старт/пауза/reset, забавен кадър и time-lapse, резерв на хода, навиване с ротора |

- **Енергиен път:** ротор → magic lever → основна пружина → колела → ход (escapement) → баланс.
- **21 600 полутрептения/час:** балансът е 3 Hz, ходовото колело прави 12° на полутрептение, а секундната стрелка се мести на 6 малки стъпки в секунда.
- **Избор на част:** клик върху детайл показва името му, функцията му, с кои части работи и мястото му в енергийния път.
- **Ден/дата:** реални дискове зад прозореца на 3 часа, които се сменят в полунощ или с бутони.
- **Честност:** при всяка част пише дали е взета от снимките, дали е документиран факт за 6309, дали е схематична или опростена.

## Референции

- **Външност:** колажът със снимки на моя часовник (`references/personal-watch-reference-collage.png`).
- **Механизъм:** в пакета нямаше снимки на механизма, каталог на частите или сервизен наръчник. Затова механизмът следва архитектурата на 6309 (magic lever, Diashock, 17 камъка за 6309A, без ръчно навиване и без hacking), но позициите и формите на частите са **схематични**. Това е отбелязано в приложението (бутон *References*).
- Оригиналното задание е в `docs/FABLE_PROMPT.md`.

## Пускане на Mac

```bash
cd ~/"Desktop/Developer/personal projects/seiko-6309"
npm install
npm run dev
```

После отвори адреса, който Vite показва (обикновено http://localhost:5173).

Build за продукция: `npm run build` (резултатът е в `dist/`).

## Управление

- Мишка: влачене за въртене, scroll за zoom, десен бутон за преместване.
- `1`–`6` сменят режима, `R` връща камерата, `F` приближава избраната част, `Esc` маха избора, `Space` пуска/спира симулацията.

## Структура

```
src/
  core/      материали, текстури (генерирани с canvas), геометрия, камера
  watch/     корпус и гривна (exterior.ts), механизъм (movement.ts), регистър на частите
  sim/       кинематика, резерв на хода, ротор
  data/      описания на частите и стъпките на сглобяване
  ui/        интерфейс
```
